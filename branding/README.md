# Branding

The red "editorial" set: a pixel-art folded newspaper on a 32×32 grid.
- Palette: cream #F3E9D2, ink #1D1B18, charcoal #22201D, red #B83A2E, gold #E0A55E.
- `solid-*.png`: icon on charcoal, at 32, 64, 512 and 1024. Use these for listings.
- `transparent-*.png`: the same icon with real transparency.
- `social-1280x640.png`: the GitHub social preview.
- `header-1200x400.png`: the Hangar and Modrinth header.

Made with an AI image tool, then normalised to the grid and palette. Fine for GitHub and Hangar. Modrinth does not
allow AI-made images on project pages (rules §6.2(1)), so a hand-drawn icon is needed there.
