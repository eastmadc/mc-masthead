# Support

Masthead is a hobby project maintained by one person in spare time. Support is best effort: issues are read, not
promised a fix or a timeline. Bug reports need `/masthead status share` output, never `config.yml`. Only the latest
release is supported. Report security problems privately (GitHub private vulnerability reporting), not in a public
issue. Masthead is provided as-is (see LICENSE); your AI provider bills you, not Masthead.
